Ödeme nasıl oluyor

Bu sitede ödeme sayfası yok. Ödeme GitHub Sponsors üzerinden yapılıyor, erişim Discord'dan veriliyor.

  1. Katmanı seç. GitHub Sponsors'ta katmana göre aylık ya da tek seferlik destek ol.
  2. Erişim iste. Discord sunucusunda #pro-request kanalına GitHub adınla yaz.
  3. Giriş yap. Giriş bilgisi ve anahtar gelir. Anahtarı uygulamadaki Account sekmesine gir.

İade

Pro işine yaramazsa ödemeden sonraki 7 gün içinde iste, o ödemenin tamamını geri al. Founder'da bu süre 14 gün. Discord ban'ı iade sebebi değil, risk baştan açıkça yazıyor. İade politikasının tamamı, İngilizce.

Pro kapalı betada. Pürüz çıkarsa #pro-feedback kanalına yaz.
